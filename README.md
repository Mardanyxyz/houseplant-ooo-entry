An entry for make.fun's "The Houseplant Out-of-Office" bounty: the funniest
out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

## How to run

Requires Node 22 or later. From any directory:

```sh
node main.ts
```

It writes exactly one line to `/output/entry.txt`.
